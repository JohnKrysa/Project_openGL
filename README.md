

# OpenGL Grid Game

If you simply want to play the game and do not wish to build the code (windows only): 

1.  Download the **`Latest release`** provided.
2.  Extract the contents to a folder on your computer.
3.  Find and double-click `main.exe` to run.

A minimalist arcade game where you control a cube and dodge incoming attacks.

Features
Endless Mode: Survive as long as possible as the difficulty and speed increase.

Level Editor: Design and build your own custom stages.

Level Sharing: Share your maps or play others using txt files.

Sharing Levels
Exporting
Open the Level Editor and build your level.

Click Export to save your builded level into levels/ folder.

After that you can simply copy the txt file and send it to whoever you want.

Importing
You need to have an exported txt file from Grid Dodge saved somewhere on your PC.

Go to Import Level in the game located in cusom levels menu.

Write the path to the location of the level you want to import and press enter.

If you wrote the path corectly, you should see the imported level in your custom levels menu.
